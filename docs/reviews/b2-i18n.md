## Non-blocking (ordered by importance)

- **N1 (process, high). Recording from `/` can land on Spanish.** `proxy.ts:13-16` redirects `/` by cookie, then `Accept-Language`. A Chrome profile with es-AR gets `/es`, so a take started at https://keyhold-app.vercel.app would be Spanish. `docs/submission/demo-script.md` ("Before you press record") and `recording-brief.md` say to open the root URL. Fix in docs: open `https://keyhold-app.vercel.app/en` explicitly. Same for the README live-demo link (README.md:9) and the form links: use `/en` for judges.
- **N2 (demo robustness, medium). ES search chip uses "2 ambientes" but the catalog data is 2 dormitorios.** `lib/i18n/chips.ts` (es[0]) + `lib/agents/listings.ts` (new "N ambientes -> N-1 bedrooms" rule). Verified with tsx: `parseSearchCriteria(CHIP_TEXT.es[0])` gives `{zone:'Tres Cerritos', max_price:500, bedrooms:1, pets:true}`; the EN chip gives `bedrooms:2`. prop-01/02 have 2 bedrooms, so if the model path is unavailable (daily cap reached, replay miss) the deterministic fallback for the ES chip finds nothing. The recorded model answer works (replay passes) and returns the 2-bedroom flats, which is itself semantically off for a reader who asked "2 ambientes". Suggest changing the ES chip to "2 dormitorios cerca de Tres Cerritos, menos de 500 USDC, acepta mascotas" and re-recording that one chip.
- **N3 (copy, low). Register switch.** `lib/agents/orchestrator.ts:264` says "Su huella SHA-256 es ... va a quedar registrada" (formal) while everything else uses tú/vos ("Tus documentos", "Subí", "Contame"). Change to "Su" -> "La huella SHA-256 es ...". The contract text itself uses formal "consulte" which is acceptable for a legal-style template.
- **N4 (UX, low). Language switch drops the conversation.** `ChatShell key={lang}` plus per-language sessionStorage key means switching ES<->EN mid-flow shows an empty chat in the other language (the old one is kept under its own key, so switching back restores it). Intentional (contract text and hash are per language) but worth one line in the demo notes: do not switch language mid-take.
- **N5 (docs, low). README does not mention the ES/EN routes, the per-language contract hash, or that the Verify button only matches a contract against its own language's hash.** Add 2 lines under "What was built" and the CHANGELOG entry already exists.
- **N6 (info). `/api/lease` can be called again with another `lang` after a deposit, producing a new lease id and hash.** This is pre-existing (the lease id was already random per call), not a regression, and the session is HMAC-signed so the client cannot forge a hash. Not caused by B2.
- **N7 (info). `//evil.com` request path returns 308 to `/evil.com`**: Next's own slash normalisation, same-origin, not from proxy.ts.
